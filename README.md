# Invitaciones Digitales 

Invitación digital interactiva para eventos especiales como bodas, XV años y celebraciones.

## Características
- Diseño responsive
- Cambio dinámico de themes
- Reproductor de música
- Contador regresivo
- Confirmación de asistencia
- Integración con Google Maps
- Animaciones suaves
- Estructura escalable para componentes reutilizables

## Tecnologías
- HTML5
- CSS3
- JavaScript
